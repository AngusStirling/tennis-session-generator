# Tennis Session Generator

A simple web app for generating age and ability appropriate tennis coaching sessions.

## Features

- Select a player age group
- Choose from valid ability levels
- Generate randomised tennis sessions
- Warm-up, mini tennis, main session and coach's notes
- Avoids immediately repeating the same session content

## Built with

- HTML
- CSS
- JavaScript
